## تفعيل المصادر يدويًا
- `SourceItem.isEnabled` قيمته الافتراضية `false`.
- التثبيت الجديد يحفظ علامة تهيئة فقط ولا يفعل أي مصدر تلقائيًا.
- التثبيتات القديمة التي كانت تفعّل مصادر افتراضيًا تُرحّل إلى حالات disabled مرة واحدة.
- شاشة التصفح تعرض المصادر المفعلة فقط، بينما شاشة الإعدادات تعرض الكتالوج وتسمح بتفعيل المصادر يدويًا.
- توجد اختبارات تغطي التثبيت الجديد، وترحيل الحالات القديمة، والقيمة الافتراضية للمصدر.

## Manga Pro / ProComic — نتيجة المراجعة
- لا يوجد Parser باسم MangaPro أو ProComic في مكتبة `kotatsu-parsers-redo` عند البحث في الإصدار الذي تمت مراجعته؛ التطبيق يملك Connector مخصصًا.
- مسارات البحث والتفاصيل والفصول تستخدم JSON API بدل الاعتماد على قائمة HTML ثابتة.
- هوية العمل تحفظ ID ونوع المحتوى وslug. الفصول تقبل اللغة العربية وتستبعد الفصول المقفلة.
- الصفحات تستخرج من قارئ الموقع الفعلي عبر WebView session دائمة لأن القارئ lazy-loaded؛ الصفحة قد تكون صورة واحدة أو قطعًا متعددة تحتاج تركيبًا.
- اعتراض الصور محدود إلى `*.procomic.im` ومسارات الصور المعروفة، ويحفظ bytes ليستهلكها مسار التنزيل/القارئ.
- توجد اختبارات Robolectric لبيانات العمل وهوية العمل وDTO الفصول والفلاتر وسلوك slot script. لكن هذه الاختبارات لا تعادل اختبار اتصال حي بالموقع.
- ما زال `ProComicConnector.kt` في طبقة التطبيق؛ توحيد مكان المحللات في الوحدة المحلية قرار معماري مفتوح.
